# API Specification

| Method | Endpoint | What It Does | Login Needed? |
|---|---|---|---|
| POST | /api/register | Create a new user account | No |
| POST | /api/login | Log in a user | No |
| GET | /api/items | Get a list of the user's items | Yes |
| POST | /api/items | Add a new item | Yes |
| DELETE | /api/items/:id | Delete an item by ID | Yes |
